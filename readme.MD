# Disciplina de Sistemas de Informação

## Contexto

Trabalho da disciplina de Sistemas de Informação. Neste trabalho, será aplicado conhecimentos de Sistemas de Informação para projetar um sistema a ser implementado no fim do semestre.

## Sistema

**Plataforma Local de Avaliação de Segurança de System Prompts em SLMs.** O sistema testa, de forma totalmente local, se um chatbot baseado em SLM viola as regras definidas em seu system prompt. As regras são definidas pelo operador; o sistema pode sugerir regras adicionais para confirmação.
